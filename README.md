# 天津大学化工热力学学生自主学习网站 | TJU-ThermoHub

**[打开在线学习网站](https://untholionleen.github.io/TJU-ThermoHub/)**

本仓库保存网站源代码与工程资料。网站使用者请进入上方在线页面；开发者可按本说明运行测试与构建。

## 当前计算功能（13.2.0）

- 纯物质 van der Waals、RK、SRK、PR 立方型状态方程及其根、Z、逸度系数与偏离性质。
- 由真实 EOS 计算的 P–V 等温线、P–T 等容线、V–T 等压线与可旋转 P–V–T 曲面；原始 EOS 曲面不代表稳定汽液平衡包络线。
- PR EOS 模型生成的约化压缩因子曲线与 CSV 导出；该曲线不是 Lee–Kesler 普遍化图。
- **IAPWS-IF97 Region 1–5 正向 P–T 物性计算**，自动区域判定；Region 4 饱和液/汽性质与 P–x、T–x 干度混合；支持上游方程实际覆盖的 PH/PS/HS 反算组合。
- 水/水蒸气 log p–h 与 T–s 图：由 IF97 状态方程计算饱和边界、质量干度线和等压线；提高饱和穹顶与等压线采样密度，纳入 Region 5 高温区，并使用细分工程网格。
- 用户自定义表格的线性、双线性插值；范德华方程 D1 逐步推导。
- 中英文独立切换、16 种物质参数、术语与符号、单位换算、本地记录 JSON/CSV 导出。

## IF97 覆盖范围与限制

- Region 1–5 的 PT 正向状态计算覆盖 IAPWS-IF97 的适用区域；Region 5 最高温度 2273.15 K、压力不超过 50 MPa。
- 饱和性质在 Region 1/2 与 Region 3 密度求根上计算；干度混合物的 v、h、u、s 采用质量干度线性混合。
- 上游 NeutriumJS PH/PS/HS 旧版反算模块没有覆盖所有区域，特别是 Region 5 的反算不可用；界面拒绝不支持的反算组合，不会伪造数值。
- 本项目引用的 NeutriumJS.thermo.IAPWS97 依 CC BY 4.0 发布，原作者、许可与修改说明见 `assets/vendor/if97/`。它是第三方实现，并非 IAPWS 官方软件；该旧包已弃用，现代继任项目链接见数据来源页。
- 参考点回归测试用于检查关键状态，不等同于对所有边界与所有后向方程完成认证。

## 构建、测试与本地运行

需要 Node.js 24 与 Python 3：

```bash
npm run check
npm run build:standalone
python -m http.server 8000
```

浏览器访问 `http://localhost:8000/`。单文件离线版输出到 `build/TJU-ThermoHub-13.2.0-standalone.html`。
