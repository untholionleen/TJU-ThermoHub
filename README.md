# 天津大学化工热力学学生自主学习网站 | TJU-ThermoHub

**[打开在线学习网站](https://untholionleen.github.io/TJU-ThermoHub/)**

本仓库是天津大学化工热力学自主学习网站的源码与维护入口。网站以用户提供的《化工热力学》第三版、项目总体计划书和部署方案为主要设计依据。当前版本为 **13.3.0（Nv3.1.0 计划基线）**。

## 已接入且有自动化测试的计算功能

- **纯物质立方型 EOS**：van der Waals、RK、SRK、PR；计算实根、Z、摩尔体积、逸度系数和模型剩余性质。
- **二元 PR/SRK VLE 模型计算器**：闪蒸、定温泡点压力/露点压力、定压泡点温度/露点温度；采用 φ–φ 平衡与二次混合规则，输出物料与逸度残差。二元交互参数 kij 必须以可靠数据核实，默认 0 仅为起始假设。
- **Lee–Kesler–Plöcker 双参考流体关联**：由 Helmholtz 剩余方程生成 Z、逸度系数、剩余焓/熵，并提供曲线和 CSV 导出。
- **IF97 水和水蒸气**：Region 1–5 的 PT 正向区域计算、Region 4 饱和性质；Region 5 的 PH/PS 温度反算限制在 P ≤ 50 MPa。对不支持的区域组合明确拒绝。
- **工程图形**：EOS P–V–T 三维曲面与二维投影；PR 压缩因子曲线；IF97 log p–h 与 T–s 数值采样图；LKP 普遍化 Z 曲线。
- **教学与附录**：D1–D11 可播放推导步骤、主要符号、术语、教材第三版附录常数、单位换算、本地 JSON/CSV 导出。

## 明确的未完成 / 待核验项

- PRG 定义与可复核参数来源尚未确认，因此不开放为可计算模型。
- 教材 Zc≠0.27 修正图需数字化和逐点核对。
- 空气 H–T、T–s、H–s 与 R-134a log p–h 图尚待独立数据/系数及参考态验证。
- IF97 全部 PH/PS/HS 变量组合，特别 Region 5 HS，仍需完整后向测试；不可将 PT 五区实现等同于所有后向组合已覆盖。
- D1–D11 已有教学步骤草稿，但全部处于教师/教材逐式审核前状态；步骤已录入不等于学术审核完成。
- VLE 是模型计算器，不是实验数据回归数据库；极性/缔合体系及缺少可信 kij 的体系不应直接用于工程设计。

未完成项在页面“工程图表接入清单”和推导区明确标示，不会用随机、硬编码或模拟值伪装完成。

## 数据、来源与版权

- 教材常数与附录信息按用户提供的《化工热力学》第三版附录1/2转录，保留教材版本值，不覆盖计算内核各自声明的 SI 常数。
- IF97 第三方实现的署名与许可说明保留在 assets/vendor/if97/NOTICE.md；上游实现已弃用，并非 IAPWS 官方软件。
- LKP 方程系独立 JavaScript 实现，公式与回归点参照 NIST-hosted teqp 文档。

- Supabase、账户、登录、OTP 与云端存储在本期完全关闭。

## 本地运行与测试

需要 Node.js 24 与 Python 3：

```bash
npm run check
npm run build:standalone
python -m http.server 8000
```

浏览器访问 http://localhost:8000/。CI 流程会顺序执行语法检查、核心 EOS 测试、IF97 回归测试、LKP 回归测试和 VLE 物料/逸度平衡测试；任何测试失败均会阻止 Pages 发布。测试数量不以固定总数判断，避免因新增测试而错误返回 exit code 1。

## 部署

GitHub Pages 由 .github/workflows/pages.yml 负责。主分支推送后先 Verify，再 Build，最后 Deploy。生产站点只发布运行文件，不发布 docs/、tests/ 和 legacy/。
