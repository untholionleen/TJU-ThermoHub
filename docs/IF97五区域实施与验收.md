# IF97 五区域实施与验收记录（13.1.1）

## 1. 实施结论

本次将 IAPWS-IF97 五区域正向 P–T 计算接入浏览器站点：

- Region 1：压缩液体的 Gibbs 方程。
- Region 2：过热蒸汽的 Gibbs 方程。
- Region 3：高密度/近临界流体的 Helmholtz 方程；主状态计算调用上游 Region 3 分区方程与后向体积关联。
- Region 4：饱和压力/温度关系；在 Region 1/2 饱和侧直接取饱和液/汽，在 Region 3 饱和侧对密度求根提取液、汽两根。
- Region 5：高温蒸汽正向 P–T 方程。

引擎通过 `ThermoIF97` 适配层对网页暴露，并按 P、T 自动判区。

## 2. 适用范围

按 IAPWS-IF97（Revised Release 2012）的分区范围和边界判定：

| 区域 | 温度范围 | 压力/边界 |
|---|---:|---|
| Region 1 | 273.15–623.15 K | 饱和液侧/压缩液体侧；上限由饱和线与区域边界决定 |
| Region 2 | 273.15–1073.15 K | 饱和汽侧及 B23 边界低压侧 |
| Region 3 | 623.15–863.15 K | B23 边界高压侧，最高压力 100 MPa |
| Region 4 | 273.15–647.096 K | 饱和曲线 |
| Region 5 | 1073.15–2273.15 K | 压力不超过 50 MPa |

总压力输入边界采用上游实现的 0.000611213–100 MPa。精确临界点和三相点邻域需要特别审视方程分区，不应将近临界区简单当作一般状态点。

## 3. 对外输入组合

| 输入组合 | 实现 | 边界说明 |
|---|---|---|
| P–T | 是 | Region 1、2、3、5 正向方程；精确位于饱和曲线时要求输入干度 |
| P–h | 是（上游支持范围） | Region 1–3 后向方程；在饱和两相范围按 h 反算干度；不提供 Region 5 反算 |
| P–s | 是（上游支持范围） | Region 1–3 后向方程；在饱和两相范围按 s 反算干度；不提供 Region 5 反算 |
| h–s | 是（上游支持范围） | 上游覆盖区域；两相区另外用饱和温度后向关系并通过 h、s 双重一致性恢复干度 |
| P–x / T–x | 是 | Region 4 饱和状态；x 为质量干度，限定 0–1 |

两相混合物的比体积、焓、内能和熵按质量干度线性混合。两相区 cp、cv 和声速不由这一杠杆规则给出，因此 UI 显示为“未定义/—”，不会用单相值填充。

## 6. 工程图生成方法

- log p–h：饱和穹顶来自 Region 4/1/2/3；质量干度线根据饱和液汽焓与压力绘制；等压线通过固定 P 多点求解 PT 状态。
- T–s：饱和液/汽边界来自 IF97 饱和性质；干度线以熵进行质量混合；等压线由 PT 状态采样。
- 绘图器包含明确坐标范围、主网格、刻度、轴名、图例、线型与指针读数。近临界区网格密度仍需专项加密与图形验收。
