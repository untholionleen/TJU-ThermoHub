# 13.3.0 模型扩展与验收范围

## Lee–Kesler–Plöcker 双参考流体模型
新增独立 JavaScript 实现，采用两参考流体 Helmholtz 剩余项，生成压缩因子、逸度系数、剩余焓和剩余熵。纯流体约化态输入范围限制为 0.3 ≤ Tr ≤ 5、0 < Pr ≤ 30。数值搜索无正密度根或参数越界时明确报错。混合物采用 LKP reducing rules；温度交互参数矩阵默认取 1，实际工程混合物必须以实验数据确定交互参数。
回归包括 NIST-hosted teqp LKP 文档中的 methane/nitrogen αr 示例、纯流体 Z/φ、低压理想气体极限和压力反算。该实现按公开方程独立编写，不复制 teqp 源码；尚不声称与教材图2-7/2-8逐点完全一致。

## 二元 PR/SRK φ–φ VLE
新增二元 PR/SRK 混合物模型计算器，采用 van der Waals one-fluid quadratic mixing rule：
aᵢⱼ = √(aᵢaⱼ)(1−kᵢⱼ)，aₘ = ΣᵢΣⱼxᵢxⱼaᵢⱼ，bₘ = Σᵢxᵢbᵢ。
实现等温等压闪蒸、定温泡点压力/露点压力、定压泡点温度/露点温度。K 初值使用 Wilson 相关，后续迭代两相逸度系数，并检查物料衡算、Rachford–Rice 残差和逸度残差。用户必须提供/确认二元交互参数 kij；默认 0 只是初始假设，不表示实验回归值。仅适用于二元 PR/SRK 教学与初步计算，不是实验回归的 VLE 数据库；极性/缔合体系及临界附近结果须谨慎使用。

## IF97 后向计算扩展
Region 5（T > 1073.15 K 且 P ≤ 50 MPa）增加 PH、PS 温度反算，内部以 Region 5 PT 方程作为状态函数作括区求根。超过 50 MPa 且焓/熵指向 Region 5 时拒绝计算。HS 后向计算仍按第三方 HS 引擎可验证的输入域工作，不声称覆盖全部 Region 5 HS。
